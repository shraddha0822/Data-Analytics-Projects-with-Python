This repository contains a collection of projects completed as part of the "Data Analytics with Python Programming" course offered by the esteemed Indian Institute of Technology, Guwahati, in collaboration with RBPL. These projects cover a range of topics and real-world scenarios, showcasing practical applications of data analytics using Python.

Chennai Water Crisis Analysis

1. Analyzed reservoir water availability dataset (~1,200+ daily records across 4 reservoirs).

2. Processed time-series data (date, month, year) for trend and seasonal rainfall analysis.

3. Visualized yearly and monthly variations in water levels using bar and line charts.

4. Derived insights on monsoon patterns and the 2019 water shortage crisis using Python (Pandas, Matplotlib, Seaborn).

Aircraft Crashes Data Analysis

1. Explored global aircraft crash history dataset (~5,000+ records from 1908–present).

2. Analyzed crash patterns by year, month, location, and aircraft type.

3. Identified top years (1972, 1968, 1989) and aircraft models (e.g., Douglas DC-3) with maximum crashes.

4. Conducted survival analysis, including crashes with zero survivors, using Python visualization libraries.

Fandango Movie Ratings Bias Study

1. Analyzed Fandango’s movie ratings dataset (~146 films from 2015) alongside Rotten Tomatoes & Metacritic scores.

2. Preprocessed rating data (stars, votes, critic vs user scores) for consistency.

3. Visualized rating distributions and identified systematic inflation in Fandango scores.

4. Demonstrated statistical bias using normalization, KDE plots, and comparative analysis.

Zomato Restaurant Data Analysis

1. Worked with Zomato Bangalore dataset (~51,000 restaurant records).

2. Cleaned and preprocessed data (ratings, cost, locations, restaurant types).

3. Analyzed order patterns (online vs offline, booking vs non-booking) and customer preferences.

4. Visualized insights on top 10 popular locations, pricing trends, and leading restaurant chains.
